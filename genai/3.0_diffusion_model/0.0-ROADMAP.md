# A: Diffusion and Flow Foundations

This series follows reading-guide 4.3a-4.3e: DDPM/DDIM, category conditioning
and CFG, VP score with classifier guidance, and independent linear CFM / first
Rectified Flow. It contains **13 numbered Python entries**, including the three
shared data/evaluator entries. The eight modern model units are in the sibling
[B: Modern Visual Generation](../4.0_modern_visual_generation/0.0-ROADMAP.md).

The two series share Food-101, the same sample IDs and category mapping, and
256 x 256 RGB. Their source-code split does not change datasets, output paths,
checkpoint format, training targets, or existing checkpoint identities.

## 1. Common data and representation

Run from the repository root in the locked project environment:

```bash
uv sync --locked --extra diffusion
uv run --locked --no-sync python genai/3.0_diffusion_model/0.1_prepare_data.py --download
```

`--data-dir` defaults to `data/food101`. The official archive lives inside
`food-101/`; `diffusion_manifest.json` contains relative image IDs and the
same alphabetical class mapping for every lesson. Downloading and manifest
preparation are explicit, separate operations from training.

| Split | Images per class | Total | Use |
|---|---:|---:|---|
| Train | 700 | 70,700 | Generator, codec, classifier and regression training |
| Validation | 50 | 5,050 | Checkpoint/configuration/guidance selection |
| Official test | 250 | 25,250 | Final evaluation only |

The validation IDs are selected deterministically from the official 750
training images per class, using split seed 42. No generator sees validation
or test images as training examples. Unconditional models use the same image
IDs and ignore labels. Food-101's training labels contain noise; a category
classifier is an imperfect evaluator, not ground truth for generated images.

Images use bicubic short-edge resize, center crop, RGB conversion and `[-1,1]`.
Only training adds horizontal flips. SR3 derives its 128px observation **after**
the shared geometry, with antialiased bicubic downsampling. Its output and
high-resolution target remain 256px. For a category cascade, train the same
conditional DDPM entry at 128px on the same manifest; this is a separate
checkpoint, not a resized 256px model.


The shared preparation and clean category evaluator stay in this directory.
B reuses them; it does not prepare a second dataset or train another evaluation
classifier. Its KL codec and frozen latent contract are described in the
[modern-series roadmap](../4.0_modern_visual_generation/0.0-ROADMAP.md).

## 3. Train and evaluate

Run from the repository root. Training objectives and optimizer/EMA updates
remain visible in each training script; paired evaluation entries only load
frozen models. Default outputs remain `output/diffusion/<model>/`; set
`DL_OUTPUT_ROOT` or pass `--output-dir` for a cloud volume.

```bash
uv run --locked --no-sync python genai/3.0_diffusion_model/1.0_ddpm.py --precision bf16
uv run --locked --no-sync python genai/3.0_diffusion_model/2.0_class_conditional_ddpm.py --precision bf16
uv run --locked --no-sync python genai/3.0_diffusion_model/0.2_class_evaluator.py
uv run --locked --no-sync python genai/3.0_diffusion_model/0.3_class_evaluator_evaluation.py --split validation
uv run --locked --no-sync python genai/3.0_diffusion_model/2.1_class_conditional_ddpm_evaluation.py \
  --class-evaluator output/diffusion/class_evaluator/latest.pth \
  --split validation --examples 5050 --solvers ddim --steps 25 50 --guidance 1 2 4
```

For VP guidance, train `3.1_noisy_classifier.py`, then supply its checkpoint
as `--noisy-classifier` to `3.3_vp_score_sde_evaluation.py`. The independent
clean classifier remains the `--class-evaluator`. Use validation to select
settings and the official test split only for the final report.

Fresh runs require an empty output directory and never clear old experiments.
Resume with `--resume-from latest.pth`. Format-4 checkpoints preserve parameters,
EMA, optimizer and RNG state, data/algorithm contracts and identities. Resume
starts at the next epoch; a `--max-steps` partial epoch is not replayed.
Keep named copies of checkpoints for selection and comparisons.

## 4. Shared monitoring and implementation

Training writes `training.jsonl`, `training_curves.png`, `latest.pth` and fixed
noise/category grids. `--sample-every` defaults to each epoch; `--eval-every 10`
adds KID on 2,020 validation images. Zero disables the corresponding monitor.
Classifier training reports its own classification metrics instead of KID.

Full evaluation uses the fixed Clean-FID feature protocol, FID/KID, feature
precision/recall, independent category compliance and class diversity, warmed
sampling throughput and batch-one latency. It counts actual CFG branches and
VP classifier input-gradient work. `--preview-only` produces images without a
quality claim. The complete shared protocol, including SR metrics, is described
in [B's evaluation section](../4.0_modern_visual_generation/0.0-ROADMAP.md).

[dl_utils/diffusion](../../dl_utils/diffusion/) owns foundation models and shared
utilities. [data.py](../../dl_utils/diffusion/data.py) owns the sample manifest
and image resizing; [solvers.py](../../dl_utils/diffusion/solvers.py) owns ordinary
velocity integration. The foundation checkpoint/sampling defaults construct
only foundation models. Common monitoring/evaluation functions accept the
constructors supplied by B, without importing `dl_utils.modern` themselves.
Neither series imports the GAN or VAE model-family packages.

## 5. Local verification and migration

```bash
uv run --locked --no-sync pytest -q tests/test_diffusion_lessons.py
uv run --locked --no-sync ruff check dl_utils/diffusion dl_utils/modern genai/3.0_diffusion_model genai/4.0_modern_visual_generation
```

The existing ignore policy keeps `tests/` local; a fresh clone contains the
runnable lessons but not that local suite. It exercises algorithm/gradient
boundaries, all 18 training loops across A/B, checkpoint restoration, numerical
migration equivalence, dependency direction and both evaluation families.
Synthetic fixtures are not Food-101 training or quality evidence.

A's script numbers `0.x-4.x` are unchanged. Previous `5.x-12.x` entries moved to
`genai/4.0_modern_visual_generation/` and became `1.x-8.x`, respectively. Their
model-specific modules moved to `dl_utils/modern/`. No duplicate script aliases
remain. Default result/checkpoint directories and format-4 state dictionaries
are unchanged; no retraining is needed solely for this directory move.
